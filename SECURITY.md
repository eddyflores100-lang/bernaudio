# Security Policy

## Supported project

Security reports are welcome for the BernAudio Model 80 web application and its repository.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the repository owner through the private vulnerability-reporting option on GitHub (Security → Advisories → Report a vulnerability), if enabled. Otherwise contact AliceLabs through its published business contact channel and include:
- affected version, page or module;
- browser and operating system;
- steps to reproduce and expected versus actual behavior;
- impact and any safe proof-of-concept.

Do not include private recordings, personal data, credentials or live customer information.

## Scope and safety

BernAudio processes microphone input locally in the browser for its audio-analysis features. Treat exported session files and any optional location data as potentially sensitive. Review exports before sharing them. Never commit API keys, credentials, private recordings or personal data.

The application is an analysis and simulation aid, not a certified sound-level meter or substitute for calibrated measurement equipment. Report security issues separately from measurement accuracy or feature requests.
